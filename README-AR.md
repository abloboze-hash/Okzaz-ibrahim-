# مشروع WhatsApp Bot — نسخة بداية

مشروع تجريبي منظم بـ Node.js وBaileys وPlugins. الردود محصورة في أوامر يرسلها المستخدم بنفسه وتبدأ بالبادئة `!`؛ لا توجد رسائل جماعية أو إرسال تلقائي للناس.

## المتطلبات
- Node.js 20 أو أحدث
- npm
- هاتف تملكه أو لديك إذن واضح باستخدام حسابه

## التشغيل
```bash
npm install
npm start
```

سيظهر QR في الطرفية. من WhatsApp على الهاتف: الأجهزة المرتبطة > ربط جهاز، ثم امسح QR.

## إضافة جلسة ثانية
افتح `config.json` وعدّل:
```json
"sessions": ["main", "second"]
```
ثم أعد تشغيل البرنامج. لكل جلسة مجلد مصادقة مستقل داخل `sessions/`.

## الأوامر
- `!ping`
- `!help`

## إضافة Plugin
أنشئ ملفاً جديداً داخل `plugins/` وصدّر كائناً افتراضياً يحتوي `commands` و`execute`، مثل `plugins/basic.js`.

## الصلاحيات
أضف أرقام المالك/المشرف في `database/permissions.json` بصيغة أرقام دولية من دون +:
```json
{
  "owners": ["212600000000"],
  "admins": []
}
```
لا تضع كلمات مرور أو رموز دخول داخل ملفات الكود.

## ملاحظات أمان وتشغيل
- لا تشارك مجلد `sessions/` أو ملفات المصادقة مع أي شخص؛ فهي تمنح الوصول إلى حساب WhatsApp المرتبط.
- لا تستخدم البوت لإرسال رسائل غير مرغوبة أو مراسلة أشخاص دون موافقتهم.
- Baileys مكتبة غير رسمية، وقد تتغير توافقية WhatsApp معها. استخدمها على مسؤوليتك واحترم شروط WhatsApp.
- لا يوجد تحديث ذاتي في هذه النسخة؛ لم يكن هناك نظام تحديث سابق يمكن الحفاظ عليه.
- `useMultiFileAuthState` مناسب كبداية وتجربة؛ للمشاريع الإنتاجية الكبيرة قد تحتاج مخزن مصادقة أكثر متانة.
- Termux مناسب للتجربة، لكن أندرويد قد يوقف العمليات في الخلفية. للاستمرار الدائم استخدم استضافة Node.js موثوقة.


## أوامر المجموعات (الإصدار 1.1)
كل أوامر إدارة المجموعة أدناه تتطلب أن يكون مرسل الأمر مشرفاً في المجموعة. أمر `!kick` يتطلب أيضاً أن يكون البوت مشرفاً.
- `!tagall [رسالة]` — منشن أعضاء المجموعة.
- `!admins` — عرض المشرفين.
- `!groupinfo` — معلومات المجموعة.
- `!link` — عرض رابط الدعوة (لا تشارك الرابط علناً دون موافقة المجموعة).
- `!kick @عضو` — إزالة عضو محدد بعد التأكد من الصلاحيات.
- `!welcome on` / `!welcome off` — تفعيل/إيقاف الترحيب بالأعضاء الجدد.

استخدم أوامر الإدارة بموافقة المجموعة، وتجنب الإزعاج أو المنشن المتكرر.
